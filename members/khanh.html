Khánh

Xin chào, mình là Khánh. Trong dự án này mình phụ trách xây dựng và quản lý nội dung trang chủ index.html, hệ thống điều hướng dùng chung cho toàn bộ 7 trang HTML, stylesheet assets/style.css và trang giới thiệu cá nhân này.

GitHub: @DrakyNeUwU Vai trò: Quản lý trang chủ & điều hướng nhóm Tệp phụ trách: members/khanh.html

Sở thích & Lĩnh vực quan tâm

Những mảng kỹ thuật mình thường tìm hiểu và thực hành:

  • Phát triển web tĩnh & UI gọn nhẹ
  • Quản lý mã nguồn Git & GitHub
  • Tư duy thuật toán
  • Tự động hóa quy trình

Kỹ năng hiện có

Nền tảng công cụ đang sử dụng trong môn học và dự án nhóm:

  • HTML5 Semantic
  • CSS3 Responsive
  • Git Branch & Merge
  • Pull Request & Review
  • Markdown Docs

Mục tiêu học tập

  • Làm chủ quy trình cộng tác nhóm bằng Git & GitHub (branching, code review, xử lý conflict và hoàn tác an toàn).
  • Tổ chức cấu trúc mã nguồn và tài liệu dự án mạch lạc, dễ đọc và dễ bảo trì cho cả nhóm.
  • Áp dụng thành thạo 4 trụ cột Tư duy tính toán vào phân tích và giải quyết bài toán kỹ thuật thực tế.

Ví dụ áp dụng Tư duy tính toán

Cách mình áp dụng 4 trụ cột của Tư duy tính toán để tổ chức cấu trúc website và điều phối quy trình cộng tác cho nhóm 6 thành viên:

1. Phân rã (Decomposition)

Chia website thành các phần độc lập: trang chủ điều hướng (index.html), stylesheet dùng chung (assets/style.css) và 6 trang cá nhân riêng trong members/ để từng người làm việc song song mà không đè lên tệp của nhau.

2. Nhận diện mẫu (Pattern Recognition)

Nhận thấy cả 7 trang đều lặp lại cùng thanh điều hướng, hệ thống thẻ thông tin, bảng màu và chân trang; từ đó gom toàn bộ quy tắc hiển thị vào một tệp assets/style.css thống nhất.

3. Trừu tượng hóa (Abstraction)

Giữ lại đúng những thông tin cốt lõi và đường dẫn tương đối gọn nhẹ (../assets/style.css, ../index.html), lược bỏ các thành phần kỹ thuật dư thừa như framework, backend hay cơ sở dữ liệu.

4. Thiết kế thuật toán (Algorithm Design)

Chuẩn hóa quy trình cập nhật mã nguồn thành chuỗi bước xác định: tạo nhánh riêng → chỉnh sửa → commit rõ nghĩa → push → mở Pull Request → review chéo → merge vào main (và dùng git revert khi phát hiện lỗi).
