Mình là Huy Khánh, thành viên Nhóm 1 môn Tư duy tính toán. Mình thích những sản phẩm có bố cục thoáng, cấu trúc mã nguồn gọn gàng và dễ để các bạn khác cùng đọc, cùng chỉnh sửa mà không bị rối.

Sở thích

Những chủ đề mình hay tìm hiểu ngoài giờ học:

  • Thiết kế giao diện gọn nhẹ
  • Tư duy thuật toán
  • Tự động hóa quy trình

Kỹ năng

Công cụ và nền tảng đang sử dụng trong đồ án:

  • HTML5 & CSS3
  • React + Vite
  • Pydantic & JSON Schema
  • Git & GitHub

Đóng góp cho đồ án

Các phần việc mình trực tiếp phụ trách trong đồ án chung Travel Planning Virtual Assistant và website giới thiệu nhóm:

Đồ án Travel Planning Virtual Assistant

  • Phối hợp xây dựng giao diện React + Vite cho luồng nhập yêu cầu và hiển thị lịch trình.
  • Thiết kế schema dữ liệu (Pydantic & JSON Schema) và xử lý chuẩn hóa đầu vào ở input_service.py.

Website nhóm & Quy trình Git

  • Xây dựng trang chủ index.html, bộ stylesheet dùng chung assets/style.css và mẫu trang cá nhân đồng bộ cho nhóm.
  • Làm việc hoàn toàn trên các nhánh riêng, gửi Pull Request và cập nhật phần đóng góp vào docs/REPORT.md.

Áp dụng Tư duy tính toán

Cách chia nhỏ và chuẩn hóa website 7 trang để cả 6 thành viên làm song song mà không dẫm chân lên nhau:

1. Phân rã

Tách trang chủ, file CSS dùng chung và 6 trang cá nhân trong members/ để mỗi người phụ trách độc lập một tệp.

2. Nhận diện mẫu

Gom thanh menu, bảng màu, lưới thẻ và chân trang lặp lại ở cả 7 trang về một stylesheet duy nhất.

3. Trừu tượng hóa

Chỉ giữ thông tin trọng tâm và đường dẫn tương đối gọn nhẹ, bỏ các lớp kỹ thuật dư thừa.

4. Thiết kế thuật toán

Chuẩn hóa quy trình cập nhật: nhánh riêng → chỉnh sửa → commit rõ nghĩa → Pull Request → review chéo → merge.
